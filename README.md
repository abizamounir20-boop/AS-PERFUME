# AS Perfume - متجر إلكتروني

متجر عطور فاخر بتصميم عربي + فرنسي.

## الألوان
- أسود (الخلفية الرئيسية)
- أحمر (اللون الأساسي)
- أزرق (اللون الثانوي)

## المميزات
- تصميم متجاوب (موبايل + كمبيوتر)
- سلة تسوق تعمل بالكامل (تُحفظ في المتصفح)
- 8 منتجات تجريبية
- نافذة تفاصيل المنتج
- نموذج تواصل
- واجهة ثنائية اللغة (عربي + فرنسي)

## طريقة التشغيل
1. افتح ملف `index.html` في أي متصفح
2. أو استخدم سيرفر محلي:
   ```
   npx serve .
   ```

## الملفات
- `index.html` - الصفحة الرئيسية
- `style.css` - التصميم
- `script.js` - الوظائف والتفاعل
